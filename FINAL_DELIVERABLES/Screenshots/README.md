## Known Issue: Heatmap Not Saved on Current Test Run

> [!WARNING]
> During the TC005 test, the Grad-CAM heatmap URL was returned in the API response
> (e.g. `/static/results/heatmap_4813cf7d.jpg`) but the file was NOT found on disk.
> The GradCAM exception handler in `app.py` (lines 262-263) silently swallows save errors.
> This is a known bug — see TC005 in the Testing Report.
